# 淮安试管婴儿：在淮安市的公立医院做试管婴儿成功率高不高

> 更新时间：2026-09-10 (UTC+8)

淮安试管婴儿：在淮安市的公立医院做试管婴儿成功率高不高，一起来看看吧。

35岁在淮安做试管的成功率大约在40至50%左右，这个概率是在女性的身体没有任何疾病的情况下，如果子宫有衰老或者卵子质量差，或者曾经有过流产或者胎停育等问题，成功会大幅度的下降。年纪比较大的女性因为卵细胞会老化，所以染色体发生畸变的概率也会升高。如果在试管前经过基因检查发现夫妻中有基因畸变或者平衡易位染色体的情况，通常这个家庭就不适合做一代二代试管，只能做三代。女性到36岁以上时生育力会缓慢下降，试管成功率也就降低，因此在35岁的时候尽早做试管是比较好的，趁现在成功率还比较高。

淮安目前有两家医院是可以做试管婴儿的，一家是淮安市妇幼保健院一家是淮安市第一人民医院，两家医院都有帮助过35岁以上女性成功助孕的案例，所以35岁在淮安做试管婴儿的成功率还是不错的。影响试管婴儿成功率的因素主要有：

- 1. 年龄，国内外文献报道年龄在25-34岁做试管婴儿手术的成功率最高，超过35岁以后成功率会有明显下降表现，大于40周岁成功率在20%左右，且活产率明显下降，而且对优生影响也较大；
- 2. 染色体，在一些原发不孕或有不良妊娠史的夫妇中，如果夫妇的染色体存在正常变异的话，虽然可以通过试管婴儿技术受孕，但是失败率和流产率较高；
- 3. 子宮内环境，如子宫内膜息肉、子宫内膜炎、既往手术或炎症（结核最常见）导致子宫内膜损伤，都可以影响胚胎着床，从而导致试管婴儿手术失败；
- 4. 患者不孕症状，年龄较大的原发不孕，子宫畸形严重的子宫内膜异位症、多囊卵巢综合征患者，从严重少弱精、无精症患者睾丸得不到精子，或存在大量畸形精于者，卵子畸形或发育异常者等，在试管婴儿治疗中也是失败率较高的。
