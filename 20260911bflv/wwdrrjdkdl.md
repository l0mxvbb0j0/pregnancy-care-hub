# 【立德树人·躬耕教坛 】北京大学人民医院王建六教授获评北京市优秀研究生指导教师

> 更新时间：2026-09-11 (UTC+8)

//  

近日，北京市教育委员会、北京市学位委员会公布了2023年北京市优秀研究生指导教师名单。**北京大学人民医院王建六教授被评为北京市优秀研究生指导教师。**

三十六年来，王建六坚守在医教研第一线。他重视思政教育，注重研究生人文素质培养，培养有温度的医学人才。“病患是最好的老师”等课程广受学生欢迎；提倡研究生积极参加医院的医务志愿服务平台，组织研究生参加医学大家讲授的职业精神课程，探讨职业规划，分享成长经历；组织师生参与到社会实践，实践足迹遍布48省市自治区，有效提升了医学生的思想政治素质和自主创新能力。他牵头八年制教学改革和北京大学器官系统-生殖系统课程体系改革，成效显著；践行实践育人，开设研究生临床技能课和妇产科学理论课，并坚持每周教学查房，亲自教导研究生临床思维和手术；通过五大举措：夯实基础、修订培训标准、试点设立教学手术床和教学门诊、向外拓展协同单位、加大科室和教师激励，形成了北大人民医院妇产科临床研究生手术实践能力培训模式，受国家卫健委科教司认可并推广。

主编教材8部，负责研究生必修课和核心课程3门，其中《妇产科学》是临床医学核心课程、国家级精品课程。王建六教授发起全国高校附属医院临床实践教育联盟，开展中国大学生医学技术技能大赛，编写国内首部临床操作指南并多次再版，首次推出全国高校附属医院临床教学质量评价标准，有力提升了全国临床实践教育水平。

20年来带领团队在子宫内膜癌和盆底疾病诊治方面取得了优异成果，显著提升了子宫内膜癌患者的生存率，特别是在年轻早期子宫内膜癌患者保留生育功能方面，取得突出成绩，让子宫内膜癌患者当妈妈的梦想得以实现。在盆底疾病防治方面，推出新理念，开创新术式，并大力推广普及，引领和推动了我国盆底疾病诊治工作，先后获得中华医学科技奖一等奖，中华预防医学会科技奖一等奖，北京医学科技成果一等奖等13项，获得教学成果奖3项。近三年主持代表性教学项目2项，国家重点研发计划项目2项，国自然重点1项，首发重点1项，省部级科研项目9项。专利转化1项。他主持卫健委科教司、卫健委人才交流中心、国家医学考试中心重大教学课题，带领教学团队搭建多种平台，鼓励研究生创新思维，通过文献悦读会、横向合作培养、专家指导、联合培养、国际交流等多举措提高研究生科研技能。

共带教各类研究生119人，其中研究生84人，长学制25人，博士后3人，港澳台及国外留学生7人，覆盖25个省市自治区、港澳台、多国留学生。他培养的研究生中有3位获得北京大学或北京市优秀毕业生。研究生均顺利毕业，就业率100%，遍及国内外，有些已经是当地妇幼健康领域的学科带头人，发挥重要作用。
