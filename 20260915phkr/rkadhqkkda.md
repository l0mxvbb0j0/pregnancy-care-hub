# 要二胎只生男孩生女孩做三代试管前怎么

> 更新时间：2026-09-15 (UTC+8)

女性年龄超过35岁之后，卵巢的功能就会开始衰退，而且无法通过药物等方法逆转。康贝贝三代试管中心提醒想要做试管婴儿的夫妻，在准备要二胎只生男孩生女孩做三代试管之前需要调理好身体状态。试管婴儿对于大龄女性来说，可以做到优生优育，最大可能的避免畸形儿。要二胎只生男孩生女孩做三代试管需要注意哪些问题呢?

1.完整且精密的孕前检查诊断。

2.听从医生嘱托，耐心地完成取卵方案。

3.胚胎移植前身体各方面也需要达到一定标准。身体的调理不是一朝一夕就可以达到特别好的状态，在我们平时的生活习惯中，就应该注意合理饮食、养成良好的作息习惯。下面是康贝贝三代试管中心给大家分享的一些具体如何调理身体。

一、孕前身体素质调养

1、孕前将身体调养好，假如自身存在一些慢性疾病要积极主动治疗，尽量减少对生育的影响。千万不要轻视孕前体检的重要性，对于高龄女士来说，完善身体检查能使治疗以问题为导向，备孕和治疗的效率高些。

2、生活规律、合理饮食、戒烟酒、平衡营养成分，备孕期间注意高蛋白食品，另外注意营养元素和维他命的填补。

二、孕前月经调理

1、女士月经失调会影响子宫卵巢排卵期，造成 受孕困难，此时应该早一点用药治疗。

2、在经期应多注意保暖，防止寒凉、生冷的不良刺激，劳逸结合、提升营养成分、增加抵抗力。

三、孕前卵巢调养

1、高龄女士卵巢会逐年下降，因此提议卵巢不良的女士在治疗期间要对子宫卵巢进行积极主动养护，调理卵巢功能，提升卵细胞质量。

2、补铁能够为卵细胞的发育供应动能，可以多吃一些芹菜、动物内脏等富含铜元素的食材，提升卵细胞的质量。

四、孕前孑宫调养

1、气血两亏的高龄女士可以适量的吃一些温热、补血的食物哦。

2、适量的运动以此来增加抵抗力，适量的体育运动可以提升 女士的身体素质，另外还能提升卵细胞质量，有益于优生。

3、心理调节，放松心情也是很重要的。

五、元素补充

1、维生素D类食材

维生素D属于脂溶性维他命，有助于子宫发育，改进孑宫环境。所以在试管婴儿备孕期间就可以适量的多填补一些，那样才能够为后期试管婴儿胚胎移植提供良好的孑宫生成环境。比如牛肝、牛乳制品、鳕鱼肝油、生鸡蛋、胡萝卜、南瓜子和芹菜等，都富含足够的维生素D。

2、维他命e类食材

维生素E类有助于人类对其他脂溶性维他命的吸收，可使激素分泌多极化，进而提升 怀孕的几率。

3、服用叶酸

叶酸缺少容易造成畸形胎儿，所以试管备孕期间直到怀孕期间的前3个月必须按量填补叶酸。

4、健康脂肪摄入

健康脂肪的摄入有益于调节女士体内激素，改进孑宫环境，促进排卵期，所以鸡蛋黄、牛肉、核桃、鱼类等都可以适量的多吃一些。
